# RainForge AI NEXUS ULTIMATE

Local-first Windows AI workspace under active staged development. The full master specification is not complete.

The Desktop shortcut launches an original WinForms/WebView2 native window with a bundled Python worker, React interface, SQLite storage and managed llama.cpp CPU/Vulkan processes. End users do not need Python, Node.js or Ollama. The installer includes local dictation and a basic chat model. The Windows build uses WebView2, .NET Framework 4.8 and compatible Visual C++ Runtime libraries. Clean-machine validation remains pending. Experimental Tauri source is retained but has not compiled on this host.

Implemented, with scoped tests: a 12-model catalog and imports; download/resume/hash checks; CPU/GPU/hybrid modes; local text and manually attached-image handoff; public connector search and 12 DPAPI-backed account probes; scoped coding files, unittest execution and single-file model AutoFix; managed Chromium DOM actions, bounded result checks and an iterative Browser Studio agent; selected-window Windows UI Automation Invoke/Value operations; sequential custom-agent text teams; verified notes; CSV/JSONL Dataset Studio with pinned public Hugging Face retrieval, cleaning, deduplication, deterministic splits, cards and hashes.

Start with [USER_GUIDE](docs/USER_GUIDE.md). Build instructions: [BUILD_GUIDE](docs/BUILD_GUIDE.md), [Windows installer](docs/WINDOWS_INSTALLER.md). Browser: [BROWSER_CHECKS](docs/BROWSER_CHECKS.md), [iterative agent](docs/BROWSER_AGENT.md). Dataset workflow: [DATASET_STUDIO](docs/DATASET_STUDIO.md). Resume automation through AGENTS.md and automation/STATE.json.

Private service actions/OAuth, main-composer agent integration, authorized local project previews, multi-file software factory, broader UI automation, project memory/skills, stronger execution isolation and many advanced features remain unfinished. Current development builds do not establish Codex parity or universal application support.


The Developer Console runs explicitly reviewed Python/Node workspace files and read-only Git commands, with output, cancellation and owned process cleanup. Skills can propose factual workflow notes from verified task outcomes, with review and the existing shared-memory setting. RainCode code-review reports transfer into an editable Nexus task draft through the handoff panel. See [ECOSYSTEM](docs/ECOSYSTEM.md).

Browser input supports text fields, textarea, select controls and bounded plain-text contenteditable editors. The browser prioritizes editable controls over navigation within its observation budget. Acceptance includes public Selenium/TestPages input drafts and a real local model creating a small functional website. This coverage does not establish universal website control.

The native desktop is Windows-only. Full game input, low-latency game observation, learned gameplay policies, arbitrary model size support and expert SSD streaming remain development work.
