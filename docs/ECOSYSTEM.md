# RainForge tools together

RainCode reviews supplied JavaScript and configuration locally. In its code review panel, choose Prepare Nexus handoff after reviewing the findings. Copy the JSON packet into Nexus → Code → RainCode + Nexus. Nexus validates the format and opens an editable task draft. Sending remains a separate action.

The packet contains a task and heuristic findings. It does not include the pasted source, browser profile, cookies or action permissions. Review findings are hypotheses requiring verification against the actual project.

Nexus includes a user-operated Developer Console. Open Console in the main navigation. Select Python, Node.js or read-only Git, enter an argument array and a relative coding-workspace directory, review the command and enable execution. Python uses the bundled interpreter. Node and Git require installed native tools. Output, exit code, cancellation and execution time are shown. Workspace scripts run with the signed-in user's OS permissions. This is a command runner, without a full interactive shell or PTY.

In Skills, enable workflow suggestions to collect reference notes from successful saved task records. Files must match their recorded hashes or the task must have a verified visible result condition. Review a suggestion before approving it. Approved notes use Nexus's existing shared memory across installed models and agents. Enable that memory to use the notes in inference. Removing a skill prevents that candidate from being regenerated from old history. Suggestions do not change model weights, execute scripts or replay permissions.

The current native desktop build supports Windows. A macOS native port, general game keyboard/gamepad control, real-time game perception, reinforcement learning, arbitrary multi-day software projects and SSD expert streaming remain unfinished. Browser actions support observed DOM controls and local Windows UI Automation depends on accessible application controls. Each result reports its measured verification scope.

Public source export uses scripts/prepare_public_source.py and excludes user data, models, runtime binaries, operational notes and screenshots. Binary release assets are published only after the matching build passes its platform checks and bundled dependency distribution terms are reviewed.
